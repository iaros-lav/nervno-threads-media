# nervno-threads-media
Photos and videos attached to @n_nervno Threads posts. Threads' API fetches media from a public URL, so each file is
committed here just before its post is published and served by GitHub Pages at
`https://iaros-lav.github.io/nervno-threads-media/<file>`. Source of truth: the Threads Insinuacii project
(`bin/threads_post.py --stage`). Files stay after posting.
